【一键启动与使用】
1. 双击运行【一键启动.bat】：
   - 脚本会自动检测电脑是否已安装 uv 环境；若未安装，会自动联网下载安装。
   - 自动安装/同步运行环境（首次运行约需 10~30 秒）。
   - 自动在浏览器中打开创作工作台：http://127.0.0.1:8000
   - 您可以直接在浏览器界面中创作小说、管理角色画像、配置风格指南、发起六维审稿等。

【如何彻底关闭程序】
- 【方式一（最直观）】：直接点击黑色终端窗口右上角的 [X] 关闭终端！
  系统已配置 Windows 内核级生命周期守护与单进程托管，关闭终端窗口时，后台服务、8000 端口与所有文件锁定会瞬间 100% 彻底释放，绝无任何孤儿进程残留。
- 【方式二】：在终端窗口中按快捷键 [Ctrl + C]，然后输入 Y 回车。
- 【备用保障】：若因为电脑卡顿或第三方软件干扰导致端口异常占用，双击【停止服务.bat】即可一键强力清理。

【配置 API Key】
- 在打开的 Web 界面右上角点击【⚙️ 设置】按钮，填入您的 DeepSeek API Key（或兼容 OpenAI 的 API Key）即可直接调用 AI 写作。
