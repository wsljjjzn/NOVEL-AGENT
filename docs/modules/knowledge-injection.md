# 知识注入

用户授权范围：在当前小说工作台完成知识注入，并修复文章参考指引未进入提示词的问题。

章节生成可显式开启 `use_knowledge_base`（默认关闭，保持原行为），并通过 `knowledge_query` 指定检索关键词。服务层从配置 `database.path` 指向的 SQLite 读取知识单元与段落，不创建数据库、不加载向量模型、不发送模型请求。缺库、无匹配、超时或损坏会返回明确状态与警告，正文可继续生成。

检索仅参数化查询；候选数量、查询长度、执行时间与注入文本长度均有上限。结果保留 ID、来源、类型和文本，注入以“参考资料”标识，要求不得照抄或服从资料中的指令。预览与生成复用同一检索方法，生成结果返回本次实际使用的来源。

Web 提供开关、关键词、免费预览与来源展示。预览不是锁定快照，生成时重新检索，响应中的来源为实际使用结果。文章知识指引写入已被大纲与正文读取的 `reference_materials`。
