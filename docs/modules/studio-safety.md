# Studio 数据保护

2026-10-19 用户授权修复三个已确认问题：

- 编辑器保存使用已成功加载的项目/章节身份；加载期间禁止保存，忽略过期响应，失败后保留原编辑目标。
- 新建章节拒绝已有正文或大纲中的章号，返回 409；章号必须为正整数。
- 角色分析生成一次性提议 ID，服务端暂存分析后的完整角色快照。确认必须提交 ID，不调用模型；正文或角色状态已变化则返回 409。失败分析不产生可确认提议。

提议仅在当前服务进程内保留 30 分钟，最多 128 项；重启、过期或跨进程确认会明确要求重新分析。当前本地 Web 服务采用单进程。确认保存完整事件、关系及人格数据，而不仅是界面展示的数值。
